## Priority order

### 1. Role-path / join-rule model: sign-off, then PR 3-5 (L)

Spec: `specs/role-path-model.spec.md`. The one place where code and
spec actively disagree: the merged first cut (PRs #227/#228) stores a
projected _endpoint_, while the revised spec (2026-06-21, grounded in
the canonical ORM sources) requires a projected role _sequence_
(tuple). Implementation is holding for sign-off on the revised cut
line.

- Step 0 is a decision, not code: sign off (or amend) the revised
  representation.
- Then PR 3: projected-tuple model + serde + schema + validation /
  verbalization / evaluation. PR 4: NORMA import. PR 5: NORMA export,
  RT-A against the Tests.Test1 subset-join fixture, merge id-remap.
- Why first: it is the tier-3 metamodel construct three other gaps
  consume (join set-comparison 5t9.6, derivation-rule extension,
  query vocabulary), and it gates NORMA export WS3 (item 6). Every
  week it sits, new serializer/validator work builds on the wrong
  operand shape.
